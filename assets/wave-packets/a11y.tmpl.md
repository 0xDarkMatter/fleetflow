## Method

- Check Playwright availability first: `npx playwright --version` inside the
  lane. If present, drive the relevant pages and run `axe-core` against
  them (inject via Playwright's page context) for a real automated audit.
- If Playwright or axe-core isn't available, fall back to WCAG heuristics
  read directly from the markup/component source — say explicitly in a meta
  finding that this was a heuristic pass, not an automated audit:
  - **Labels** — form inputs without an associated `<label>`,
    `aria-label`, or `aria-labelledby`; icon-only buttons/links with no
    accessible name.
  - **Contrast** — text/background color pairs that don't use the design
    system's contrast-safe tokens, or hardcoded colors that look likely to
    fail WCAG AA (4.5:1 normal text, 3:1 large text).
  - **Focus order** — DOM order that doesn't match visual reading order in
    a way that would produce a confusing tab sequence; interactive elements
    not reachable by keyboard at all.
  - **Keyboard paths** — any interaction that only has a mouse/pointer
    handler (`onClick` with no `onKeyDown`/`role`/`tabIndex`), modal/dialog
    patterns with no focus trap or escape handling.
