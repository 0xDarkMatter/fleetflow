## §1 Findings ledger contract (`ff-findings.sh`)

Ledger: `.fleetflow/<run>/findings.jsonl`, append-only JSONL. Record:

```jsonc
{"id": "qa-003",              // <wave>-<seq>, assigned at append
 "fp": "a1b2c3d4e5f6",        // first 12 hex of sha256(wave + "\n" + sorted files + "\n" + claim lowercased/space-collapsed)
 "wave": "qa",                // catalogue wave name
 "severity": "medium",        // low|medium|high|critical
 "files": ["src/x.ts"],       // repo-relative, sorted
 "claim": "…",                // one-sentence defect statement
 "evidence": "…",             // repro / observed vs expected
 "status": "open",            // open|fixed|escalated|waived
 "round": 0,                  // fix-loop round that produced/last touched it
 "lane": "qa-1",              // producing lane id
 "ts": 1786300000}            // epoch at append (ledger only — NEVER in packets)
```

CLI (flags, never positionals): `append` (JSONL on stdin or `--json '…'`;
dedupes by `fp` — an existing fp updates `round`/`evidence`, never duplicates) ·
`list [--status S] [--severity S] [--wave W] [--min-severity S]` (JSON array
stdout) · `count` (same filters; `{"open":n,…}` by status) · `set-status --fp F
--status S` · `waive --fp F --reason R` (also upserts `docs/waivers.json`) ·
`apply-waivers` (marks any open finding whose fp appears in `docs/waivers.json`
as waived). All take `--run NAME [--repo P]`. Exit 0 even when count is zero —
exit codes signal errors, not results.

Waivers file (repo-level, committed): `docs/waivers.json` =
`[{"fp": "…", "reason": "…", "waived": "2026-08-10", "expires": null}]`.
Expired entries are ignored and reported on stderr.

Severity rubric (for templates and triage): `critical` = data loss, auth
bypass, crash on main path · `high` = wrong results, injection, broken feature ·
`medium` = degraded UX, missing validation, perf cliff · `low` = polish, naming,
minor inconsistency.

## §2 Manifest `waves` contract

`phases` (strings) is FROZEN — dashboards read it; do not change its shape.
Wave state is a **sibling** key set, written only by `ff-run wave`:

```jsonc
{"posture": "tested",         // baseline|tested|hardened|complete
 "fix_rounds": 2, "severity_floor": "medium",
 "waves": [
   {"name":"qa","kind":"finder","gate":"auto","status":"done","round":0},
   {"name":"triage","kind":"barrier","gate":"auto","status":"running","round":0},
   {"name":"fix","kind":"fix","gate":"review","status":"pending","round":0}]}
```

`kind`: `build|finder|barrier|fix|docs`. `gate`: `auto` (proceed, report) ·
`review` (write state, print gate summary, exit 0 with `"gated"` on stdout —
resume via `wave --continue`) · `stop` (same but exit 14). `status`:
`pending|running|gated|done|skipped` (skipped waves are REPORTED — no silent
caps). A manifest without `waves` is a legacy manifest and stays valid — every
reader defaults it absent.

## §3 Sequencer contract (`ff-run.sh wave`)

```
ff-run.sh wave --run NAME --posture P [--attend none|land|each]
               [--gate WAVE=POLICY]... [--wave +perf,-a11y]
               [--fix-rounds N=2] [--severity-floor S=medium]
               [--dry-run] [--continue] [--repo PATH]
```

- Postures pick finder waves from the catalogue (§4): baseline → docs-parity;
  tested → +qa, regression; hardened → +security, supply-chain, a11y;
  complete → +polish. Pipeline order is fixed:
  `finders → triage → fix → re-verify (loop ≤ fix-rounds) → docs-sync`.
- `--attend` is a MACRO setting default gates (none→all auto; land→last wave
  review; each→every wave review); explicit `--gate` overrides per wave. Gates
  in the manifest are the only truth.
- Finder waves spawn one lane per catalogue entry via `ff-spawn` (`--phase
  <wave>` so per-wave cost aggregates; `--worktree`; model/effort/max-turns
  from catalogue routing). Packets are generated from templates (§4) into
  `.fleetflow/<run>/packets/<wave>-<n>.task.md`. Collect via `ff-collect`;
  a finder's schema-validated FINAL REPLY (findings array) is piped to
  `ff-findings append`.
- **Triage (barrier, mechanical):** wait all finders → `apply-waivers` → dedupe
  is inherent (fp) → group open findings at/below `severity_floor` into
  file-disjoint fix packets (union-find on `files`); above-floor or
  always-escalate (auth/crypto/permissions/schema/deps/API/ADR-governed paths —
  match via adr-touching when `docs/adr/` exists) → `set-status escalated`.
- **Fix:** one lane per group (routing §4). **Re-verify:** re-run the producing
  finder template per open finding's wave, with `BASE_SHA=$(git -C <lane> rev-parse
  HEAD)` substituted into the packet (ADR-012 corollary; `round` is metadata,
  never in the key), routed to a DIFFERENT provider than the fix lane. Refuted
  once → back to pool, round+1; **refuted twice → escalated** (anti-oscillation).
  Loop while open findings ≤ floor remain and round < fix-rounds.
- **Summary** (stdout JSON, end of run or at a gate): waves with status,
  findings by status/severity, per-wave `tokens_total`/`cost_usd` roll-ups
  (aggregate `ff-status` lanes by `phase`), skipped waves, waived count.
- `--dry-run` prints the resolved wave plan + packets without spawning.
  `--continue` resumes from manifest wave state (first non-done wave).

## §4 Wave catalogue contract (`assets/wave-catalogue.json` + templates)

```jsonc
{"waves": {
  "qa": {"kind":"finder","postures":["tested","hardened","complete"],
          "model":"sonnet","effort":"","max_turns":80,
          "template":"assets/wave-packets/qa.tmpl.md","lanes":1},
  "security": {"kind":"finder","postures":["hardened","complete"],
          "model":"codex","cross":"opus","lanes":2, …},
  …},
 "fix":       {"model":"sonnet"},
 "reverify":  {"rule":"different-provider-than-fix"},
 "always_escalate": ["auth","crypto","permissions","schema","deps","public-api"]}
```

Templates are markdown with `%%VAR%%` placeholders (`%%RUN%%`, `%%REPO_HINT%%`,
`%%BASE_SHA%%`, `%%FINDINGS_JSON%%`, `%%SEVERITY_RUBRIC%%`) — substitution via
sd/sed in the sequencer, no envsubst. Every finder template: read-only lane
(finders NEVER fix), findings-array FINAL REPLY matching §1 (schema embedded),
severity rubric pasted, no-silent-caps clause ("if you sampled, say so in a
`meta` finding"). Waves: `qa` (functional; Playwright optional — see §6),
`visual-qa` (Playwright screenshots vs `tests/visual/` baselines when present,
else describe-and-establish), `security` (Codex + Opus, different angles),
`a11y` (axe-core via Playwright when available, heuristics otherwise),
`supply-chain` (new deps since base, lockfile, scripts), `polish`
(low/medium improvements as findings; larger ideas severity=low,
status stays open→escalated as "recommend"), `perf` (opt-in), `docs-parity`
(refute the docs), `regression` (write failing-then-passing tests for fixed
findings, named for the adversary), `fix`, `docs-sync`.

## §5 Widget contract (`ff-widget.sh`)

`ff-widget.sh --run NAME [--repo P] [--max-lanes N=10]` → HTML **fragment** on
stdout for the claude.ai chat sandbox (`show_widget`). Data: `ff-status.sh
--run` JSON + manifest (`waves`, posture) + `ff-findings count`. Design
contract (chat design system): CSS variables only (`var(--surface-1|2)`,
`--text-primary|secondary|muted`, `--text-success|danger|warning|accent`,
`--bg-*`, `--border`, `--radius`, `--font-mono`); Tabler outline icon font
(`<i class="ti ti-…">`) — never `-filled`, no emoji; sentence case; no
gradients/shadows/dark outer bg; nothing external except Tabler class names
(host-loaded — zero `http` in output, mirror ADR-003); weights 400/500 only;
no font below 11px. Layout (top→bottom): **wave bar** — one horizontal
left-to-right segmented bar, one segment per wave sized equally, fill =
`var(--bg-success)` done / `--bg-accent` running / `--bg-warning` gated /
`--bg-danger` failed / `--surface-1` pending, 12px label under each segment;
**metric cell grid** — `repeat(auto-fit, minmax(110px,1fr))` cells
(`--surface-1`, radius, 10px pad): lanes done/total, tokens, ≈cost (partial
marker), findings open/total, elapsed — each cell led by a 16px Tabler icon
(`ti-layout-grid`, `ti-coins`, `ti-report-money`, `ti-bug`, `ti-clock`);
**lane cell grid** — same auto-fit grid, one cell per lane (not table rows):
state icon (`ti-check` success / `ti-loader-2` accent / `ti-x` danger /
`ti-alert-triangle` warning for stalled), mono lane id, model + wave chip,
tokens/time small line; cap at `--max-lanes`, then a "+N more" cell; **findings
strip** (only when >0): severity chips (`critical n · high n · …`) coloured by
role tints; **footer** — buttons `onclick="sendPrompt('…run NAME…')"` for
refresh / triage failed / review gate (gate button only when a wave is gated),
and `<a href="https://fleetflow.lab/?repo=%%REPO%%&run=%%RUN%%">full dashboard</a>`.
Stateless: no localStorage, no fetch, no timers (ADR-003/004/013 rationale).
Numbers rounded; tokens humanised (`8.1M`).
